Test files for the PSD reader.

- `gimp8.psd`, `gimp16.psd`: written by GIMP 3 (layers, group, mask, blend modes).
- `magick-zip.psd`: written by ImageMagick (ZIP compression, byte-reversed blend keys).
- `ps-text.psd`, `ps-clipping.psd`: written by Adobe Photoshop, from the psd-tools
  test suite (https://github.com/psd-tools/psd-tools, MIT license; originally
  `text.psd` and `clipping-mask3.psd`).
